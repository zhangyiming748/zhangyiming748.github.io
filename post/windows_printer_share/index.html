Windows开启打印机共享

2026-06-24 Windows

以下是 Windows 安全更新后恢复自带打印机共享功能的完整解决步骤（适用于 Windows 10 / Windows 11）。安全更新常会关闭部分共享功能或加强防火墙/权限限制，按顺序操作即可。

1. 设置网络为“专用”网络（最重要）

  • 打开 设置（Win + I）→ 网络和 Internet → 点击你当前连接的 Wi-Fi / 以太网 → 属性。
  • 将网络配置文件类型改为 专用。
  • 重启电脑后继续下一步。

2. 开启网络发现和文件/打印机共享

  • 设置 → 网络和 Internet → 高级网络设置 → 高级共享设置。
  • 在 专用网络 部分：
    • 开启 网络发现。
    • 开启 文件和打印机共享。
  • 在 所有网络 部分（可选，如果不需要密码）：
    • 关闭 密码保护共享。
  • 点击 保存更改。

或者用传统方式：

  • 控制面板 → 网络和共享中心 → 左侧 更改高级共享设置，同上操作。

3. 检查并启动相关服务

  • 按 Win + R，输入 services.msc 回车。
  • 找到以下服务，右键 → 属性 → 启动类型改为 自动，然后点击 启动（如果已停止）：
    • Print Spooler（打印假脱机程序）
    • Server（服务器）
    • Function Discovery Provider Host
    • Function Discovery Resource Publication
  • 重启电脑。

4. 防火墙放行文件和打印机共享

  • 搜索打开 Windows Defender 防火墙 → 允许应用或功能通过 Windows Defender 防火墙。
  • 勾选 文件和打印机共享（包括私有和公共，如果需要）。
  • 或者用命令提示符（管理员）运行：
    netsh advfirewall firewall set rule group="File and Printer Sharing" new enable=Yes
netsh advfirewall firewall set rule group="Network Discovery" new enable=Yes

5. 在共享主机上正确共享打印机

  • 打开 设置 → Bluetooth 和设备 → 打印机和扫描仪。
  • 点击你的打印机 → 打印机属性 → 共享 选项卡。
  • 勾选 共享这台打印机，设置一个简短的共享名称（如 HPPrinter）。
  • 安全 选项卡中，确保 Everyone 有 打印 权限（如果没有，添加 Everyone 并赋予权限）。

6. 常见安全更新导致的问题修复（注册表或策略）

如果以上不行，尝试以下（备份注册表后再操作）：

  • 修复常见更新导致的 RPC/Point and Print 问题：

    1. 按 Win + R 输入 regedit。
    2. 导航到 HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Print
    3. 新建 DWORD（32位）值 RpcAuthnLevelPrivacyEnabled，设为 0。
    4. 重启。

  • 其他可能需要的注册表（视具体更新）：

    • 启用不安全来宾登录（适用于工作组网络）：
      HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\LanmanWorkstation\Parameters
      新建 DWORD AllowInsecureGuestAuth = 1

操作后重启主机和客户端电脑，然后在其他电脑上添加打印机（搜索 \主机名\打印机共享名）。

额外提示

  • 确保主机和客户端在同一局域网，Ping 得通对方 IP。
  • 如果还是提示错误（如 0x0000011b），尝试卸载最近的安全更新测试（设置 → Windows Update → 更新历史记录 → 卸载更新），或更新到最新补丁。
  • 家庭版 Windows 没有 gpedit.msc，可用注册表替代。
  • 第三方杀毒/防火墙（如 360、火绒）可能拦截，需在它们设置中放行共享。

按以上步骤大多数情况下都能恢复。如果指定你的 Windows 版本（10/11）和具体错误代码，我可以给出更针对性的方法。
