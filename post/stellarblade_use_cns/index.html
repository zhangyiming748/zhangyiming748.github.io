剑星CNS相关问题

2026-06-24 Stellar Blade

CNS 是《剑星》（Stellar Blade）的一个重要 MOD 框架，全称 Custom Nanosuit System（自定义纳米服系统）。

它专门解决传统“替换型”服装 MOD 的冲突问题：

  • 普通 MOD 是覆盖原版某件衣服（容易冲突、只能选一件）。
  • CNS MOD 是新增衣服，玩家可以在游戏内通过 UI 菜单自由切换无限多套自定义服装、脸部、发型、耳环、眼镜、武器等（支持 Eve、Adam、Lily、无人机）。
  • 按 N 键（或 Alt+N）在游戏世界里（不是菜单界面！）就能呼出切换界面，非常方便。

标记了 “cns” 的 MOD 就是专门适配这个系统的，必须先装好 CNS 主框架才能用。

安装步骤（保姆级，PC Steam 版）

1. 先安装 UE4SS（MOD 加载器，必备）

  • 去 GitHub 下载 Stellar Blade 专用版（不要用 dev 开发版）：
    https://github.com/Chrisr0/RE-UE4SS/releases
  • 下载最新稳定版 zip，解压后把下面两个东西复制到游戏目录：
    • dwmapi.dll
    • ue4ss 文件夹
  • 路径：Steam\steamapps\common\StellarBlade\SB\Binaries\Win64\

2. 再安装 CNS 主框架

  • Nexus 官网下载最新版（目前 2.2 版左右）：
    https://www.nexusmods.com/stellarblade/mods/1496
  • 解压后把整个 SB 文件夹 合并到游戏根目录（覆盖/合并即可）：
    Steam\steamapps\common\StellarBlade\SB\
  • 安装完后会多出几个关键文件夹：
    • SB\Content\Paks\~mods\CustomNanosuitSystem ← 以后放纯 JSON 的 CNS MOD
    • SB\Content\Paks\LogicMods ← CNS 的核心 pak 文件在这里

3. 安装标记 “cns” 的服装 MOD

  • 大部分 CNS MOD 有两种形式：
    • 带 .pak 的完整版：直接像普通 MOD 一样解压合并到游戏 SB 文件夹。
    • 纯 .json 版（最常见）：把里面的 .dekcns.json 文件（和对应贴图）扔进：
      SB\Content\Paks\~mods\CustomNanosuitSystem\
  • 如果你下载的是传统“替换型”MOD，想转成 CNS 版，可以用 CNS Repacker 工具一键转换：
    https://www.nexusmods.com/stellarblade/mods/1936

4. 启动游戏验证

  • 进游戏后在游戏世界里（不是菜单）按 N 键，应该弹出 CNS 切换界面，能看到所有装好的 CNS 服装。
  • 如果按不出：检查 UE4SS 是否正确安装、游戏版本是否匹配、是否用了 Mod 管理器冲突。

推荐懒人方案（中文玩家最友好）

  • B站搜 “剑星 CNS 安装教程” 或 “剑星 MOD 安装器”，有很多嘴对嘴视频：
    • 阿黄玩游戏的教程：https://www.bilibili.com/video/BV1irgGzuEG3/
    • 还有一键安装器视频，能自动处理 UE4SS + CNS + 大量服装。
  • 很多大佬会打包 “CNS 懒人整合包”，下载后直接解压覆盖就行（但记得备份存档）。

注意事项：

  • CNS MOD 不会覆盖原版衣服，所以可以和替换型 MOD 混用，但优先用 CNS 版避免冲突。
  • 游戏更新后可能需要更新 UE4SS 和 CNS（Nexus 首页会标明兼容版本）。
  • Steam Deck 用户路径稍有不同，但原理一样。

装好后你就可以随便换衣服了，基本告别“只能穿一套”的烦恼！有具体哪个 MOD 装不上，贴链接我再帮你看。
